# Manual do Usuario Operacional

## Como logar

1. Abra `streamlit run operational_app/app.py`
2. Informe e-mail e senha
3. Acesse os modulos liberados para o seu perfil

## Como cadastrar colaborador

1. Entre em `Colaboradores`
2. Abra a aba `Novo colaborador`
3. Preencha os dados
4. Salve

## Como registrar admissao

1. Entre em `Admissoes`
2. Crie a pre-admissao
3. Preencha checklist e dados obrigatorios
4. Conclua a admissao

## Como aprovar ferias

1. Entre em `Ferias`
2. Crie ou localize a solicitacao
3. Use a acao `Aprovar ferias`

## Como lancar afastamento

1. Entre em `Afastamentos`
2. Registre o tipo e o periodo
3. Anexe documento quando houver
4. Encerre no retorno

## Como abrir e fechar folha

1. Entre em `Folha`
2. Abra a competencia
3. Lance rubricas
4. Revise o resumo
5. Feche a competencia

## Como desligar colaborador

1. Entre em `Desligamentos`
2. Registre a solicitacao
3. Confirme tipo e data
4. Conclua o desligamento

## Como consultar indicadores

1. Entre em `Indicadores`
2. Ajuste filtros
3. Consulte KPIs e graficos

## Como consultar qualidade operacional

1. Entre em `Qualidade Operacional`
2. Revise cards e tabela de problemas
3. Priorize os itens criticos
