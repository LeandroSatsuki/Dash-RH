# Checklist de Producao

- Trocar `SECRET_KEY`.
- Trocar `ADMIN_PASSWORD`.
- Usar PostgreSQL.
- Ativar backup do banco e de `UPLOAD_DIR`.
- Configurar HTTPS.
- Restringir acesso a rede interna, VPN ou proxy seguro.
- Revisar a matriz de permissoes.
- Revisar logs e auditoria.
- Validar exigencias de LGPD.
- Validar retencao e descarte de documentos.
- Nao subir planilhas no Git.
- Nao usar SQLite em producao.
